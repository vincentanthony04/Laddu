# PL34 Event Risk PIT Capture Closure

PL34 closes the final observed Delivery shadow-feature gap without weakening any selector or training gate.

The canonical scanner already stores a decision-time `event_risk` mapping produced from the earnings/board-meeting authority. PL34 projects that existing result into Research only when `event_risk.flag` is an explicit boolean: `true -> event_risk_score=1.0`, `false -> 0.0`. Missing or malformed authority remains missing, and any pre-existing scalar event-risk authority is preserved.

No event date is invented, no calendar is queried from the capture worker, and no production decision, risk, R:R, cost, model weight, completeness threshold or broker authority changes. The 60% feature completeness gate remains unchanged. On the exact PL33 observed feature shape, authoritative event-risk projection moves Delivery Research feature coverage from 11/12 (91.67%) to 12/12 (100%).
